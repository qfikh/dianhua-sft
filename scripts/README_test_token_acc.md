# 测试集Token准确率计算工具

## 功能概述

这个工具用于计算测试集上的token级别准确率（test_token_acc），与模型训练时的验证集eval_token_acc保持完全一致的评价逻辑。

## 核心特性

1. **与训练时完全一致的评价逻辑**：使用teacher forcing模式，只计算目标序列部分的预测准确率
2. **详细的错误分析**：提供每个样本的错误位置、错误类型统计等信息
3. **与验证集对比分析**：自动对比测试集与验证集的准确率差异，并提供解释和建议
4. **灵活的计算方法**：支持teacher forcing（推荐）和简单模式两种计算方法
5. **完整的报告输出**：生成包含汇总统计、详细结果和错误分析的Excel报告

## 安装依赖

```bash
pip install pandas torch transformers tqdm numpy openpyxl
```

## 使用方法

### 基本用法

```bash
python calculate_test_token_acc.py \
    --model /path/to/your/model \
    --data /path/to/test_data.xlsx \
    --input-col C \
    --target-col D
```

### 高级用法

```bash
python calculate_test_token_acc.py \
    --gpu 0 \
    --model /path/to/your/model \
    --data /path/to/test_data.xlsx \
    --input-col C \
    --target-col D \
    --method teacher_forcing \
    --eval-acc 0.92
```

### 参数说明

- `--gpu`: 使用的GPU编号（默认0）
- `--model`: 模型路径（默认为项目中的合并模型路径）
- `--data`: Excel数据路径（默认为项目中的测试数据）
- `--input-col`: 输入文本列，默认为'C'（第三列）
- `--target-col`: 目标文本列，默认为'D'（第四列）
- `--method`: 计算方法，可选'simple'或'teacher_forcing'（默认）
- `--eval-acc`: 训练时验证集的eval_token_acc，用于对比分析（默认0.92）

## 输出说明

### 控制台输出

1. **基本统计信息**：
   - 总样本数
   - 平均Token准确率
   - Token准确率标准差
   - 最小/最大Token准确率

   - 相对变化百分比

3. **低准确率示例**：展示准确率低于0.8的样本及其错误分析

生成包含以下工作表的Excel文件：

1. **汇总统计**：整体的准确率统计信息
2. **详细结果**：每个样本的详细分析结果
3. **错误分析**（可选）：包含错误类型统计和分析

## 算法细节

### Teacher Forcing模式（推荐）

1. 将输入文本和目标文本拼接：input + target + eos_token
2. 创建输入序列（去掉最后一个token）和标签序列（去掉第一个token）
3. 模型预测每个位置的下一个token
4. 只计算目标文本部分的预测准确率
5. 同时计算平均对数概率和困惑度

### 简单模式

直接比较输入序列的预测结果与目标序列，计算非padding token的准确率。

## 与验证集eval_token_acc的差异分析

工具会自动分析测试集与验证集准确率的差异：

- **差异<0.05**：测试集表现与验证集非常接近，模型泛化能力良好
- **差异<0.1**：测试集表现与验证集略有差异，但在可接受范围内
- **差异<0.2**：测试集表现与验证集有明显差异，可能存在过拟合或数据分布差异
- **差异≥0.2**：测试集表现与验证集差异很大，需要深入分析

## 错误分析

对于每个低准确率的样本，工具会提供：

1. **错误位置**：具体在哪个token位置出现错误
2. **错误类型**：预测token与实际token的对比
3. **错误统计**：最常见的错误类型及其频率

## 注意事项

1. 确保测试数据的格式与训练时一致
2. 建议使用teacher forcing模式以获得更准确的结果
3. 如果测试集准确率远低于验证集，建议检查数据质量或模型状态
4. 工具会自动处理不同长度的序列，使用适当的padding策略

## 故障排除

1. **显存不足**：减小batch_size或使用更小的模型
2. **Tokenizer错误**：确保模型路径正确，包含完整的tokenizer文件
3. **Excel读取错误**：确保Excel文件格式正确，指定的列存在数据
