================================================================================
                垫话规则精简手册（意图规则 + 改写规则）
================================================================================
依据版本 : SYSTEM_PROMPT_V31_1022（线上生效）
           dianhua_sft_interface.py
核心原则 : Prompt 决定「该说什么」
           代码决定「说了不该说的，怎么改成能说的」

════════════════════════════════════════════════════════════════════════════
【一】客户意图 → 期望垫话（Prompt 规则 + 代码规则）
════════════════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────────────┐
│ 意图 1 : 身份话题（询问 / 断定 / 诉求）                                   │
│ 示例   : 「你是机器人吗？」「你就是真人吧」「我要找真人」「转人工」               │
├──────────────────────────────────────────────────────────────────────┤
│ Prompt 规则 :                                                         │
│   ├─ 判定为身份话题后，只输出固定句                                       │
│   │   └─→ 了解您的问题了。                                              │
│   └─ 同时禁止：不复述、不附和、不重复真人/AI/机器人表述、                    │
│       不解释、不主动提身份、不引导转真人                                   │
├──────────────────────────────────────────────────────────────────────┤
│ 代码规则 : 无特殊处理                                                   │
│   └─ 模型若正常输出「了解您的问题了。」→ 原样下发                            │
└──────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────┐
│ 意图 2 : 负面事件（故障 / 事故 / 损失）                                   │
│ 示例   : 「车胎爆了」「撞车了」「车被划了」                                  │
├──────────────────────────────────────────────────────────────────────┤
│ Prompt 规则 :                                                         │
│   ├─ 中性承接 + 克制安抚，如                                            │
│   │   └─→ 好的，您说的这个情况我了解了。                                  │
│   │   └─→ 车胎爆了是吧，您先别着急。                                     │
│   └─ 四类违规（模型不许生成）                                            │
│       ├─ ① 渲染/评价严重程度：够呛 / 可麻烦了 / 这下难办了                 │
│       ├─ ② 情绪叹词：哎呦 / 哎呀 / 天呐 / 我的天                         │
│       ├─ ③ 调侃风凉话：这事闹的                                         │
│       └─ ④ 夸张共情：您肯定急坏了 / 太让人心疼了                          │
├──────────────────────────────────────────────────────────────────────┤
│ 代码规则 : 无拦截                                                      │
│   └─ 模型若输出「这情况，真是够呛。」→ 原样下发（代码不拦情绪违规）             │
└──────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────┐
│ 意图 3 : 普通业务咨询 / 办理                                            │
│ 示例   : 「怎么查违章」「我想改一下地址」                                   │
├──────────────────────────────────────────────────────────────────────┤
│ Prompt 规则 :                                                         │
│   └─ 简短复述客户问题要点，或确认听到的内容                                 │
│       ├─→ 好的，您说的这个情况我了解了。                                  │
│       └─ 不展开解释、不给答案                                           │
├──────────────────────────────────────────────────────────────────────┤
│ 代码规则 : 无特殊处理，仅在模型输出触发 P1~P5 时改写（见第二部分）            │
└──────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────┐
│ 意图 4 : 售前咨询（车型配置 / 车型对比 / 价格）                            │
│ 示例   : 「这个车有什么配置」「两款有什么区别」「多少钱」                      │
├──────────────────────────────────────────────────────────────────────┤
│ Prompt 规则 : 无专门规则（与普通咨询相同）                                │
├──────────────────────────────────────────────────────────────────────┤
│ 代码规则 : 不识别「售前意图」本身                                         │
│   └─ 只有当模型输出含「查一下」时才触发替换 → 售前话术池（见 P1）             │
└──────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────┐
│ 意图 5 : 敏感话题（黄 / 赌 / 毒 / 政 / 恐）                              │
├──────────────────────────────────────────────────────────────────────┤
│ Prompt 规则 : 不调用模型                                               │
├──────────────────────────────────────────────────────────────────────┤
│ 代码规则 : 敏感词拦截（AC 自动机，词库 sensitive_words.txt）               │
│   ├─ 检测范围：客户最后一句                                              │
│   ├─ 命中后：不再调用模型，直接返回随机一条                                 │
│   │   └─→ 您说的这个问题。                                              │
│   │   └─→ 您说的这个情况。                                              │
│   └─ 注意：该拦截优先于所有模型规则                                       │
└──────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────┐
│ 意图 6 : 对话为空 / 最后一句是客服                                       │
├──────────────────────────────────────────────────────────────────────┤
│ 代码规则 : 直接返回空垫话 dianhua = ""，不调用模型                         │
└──────────────────────────────────────────────────────────────────────┘






════════════════════════════════════════════════════════════════════════════
【二】模型推理结果 → 代码改写规则（P1~P5 详细清单）
════════════════════════════════════════════════════════════════════════════
说明 : 以下规则严格串行，前一条的输出是后一条的输入。
      整句替换 = 原始垫话完全丢弃；短语替换 = 只换其中一段。
════════════════════════════════════════════════════════════════════════════


┌──────────────────────────────────────────────────────────────────────┐
│ 改写规则 P1 : 原始垫话含「查一下」                                        │
├──────────────────────────────────────────────────────────────────────┤
│ 触发条件 : "查一下" in 垫话                                             │
│ 替换方式 : 整句替换（原句完全丢弃）                                       │
│ 替换结果 : 从以下 18 条中随机 1 条                                       │
├──────────────────────────────────────────────────────────────────────┤
│ 01  收到，我马上为您查询相关信息。                                        │
│ 02  正在查询相关内容，请您稍等                                           │
│ 03  我帮您看一下，请稍等。                                               │
│ 04  您稍等，我帮您查一查。                                               │
│ 05  您稍等，我去后台查一下。                                             │
│ 06  我正在为您查询，请稍候。                                             │
│ 07  请稍候，我正在为您核实相关信息。                                      │
│ 08  麻烦您稍等，我帮您查一下。                                           │
│ 09  请稍等，我帮您仔细看下。                                             │
│ 10  请稍等一下，我帮您核实下。                                           │
│ 11  请您稍等，我来确认一下。                                             │
│ 12  您稍等，我帮您核实一下。                                             │
│ 13  请稍等，我核实一下。                                                │
│ 14  我帮您核实一下。                                                    │
│ 15  我这就帮您看看，请稍等。                                             │
│ 16  请您稍等一下，我来帮您确认。                                          │
│ 17  正在查找相关信息，麻烦您等一下。                                       │
│ 18  请稍等，我来帮您查查。                                               │
├──────────────────────────────────────────────────────────────────────┤
│ 示例 : 「好的，我帮您查一下。」 → 「请稍等，我帮您核实下。」                    │
└──────────────────────────────────────────────────────────────────────┘


┌──────────────────────────────────────────────────────────────────────┐
│ 改写规则 P2 : 原始垫话命中「过度承诺」关键词                               │
├──────────────────────────────────────────────────────────────────────┤
│ 触发条件 : 垫话中出现以下任一关键词                                       │
│   ├─ 记着 / 记下 / 记一下 / 已记录 / 已经记录 / 您记录                    │
│   ├─ 专人跟进                                                         │
│   └─ 有意思                                                           │
│ 替换方式 : 整句替换（原句完全丢弃）                                       │
│ 替换结果 : 从以下 4 条中随机 1 条                                        │
├──────────────────────────────────────────────────────────────────────┤
│ ① 了解您说的情况。                                                     │
│ ② 了解您的情况。                                                       │
│ ③ 您说的情况已了解                                                     │
│ ④ 明白您的意思了。                                                     │
├──────────────────────────────────────────────────────────────────────┤
│ 示例 : 「好的，我帮您记下来。」 → 「了解您说的情况。」                         │
│         「我安排专人跟进处理。」 → 「明白您的意思了。」                       │
└──────────────────────────────────────────────────────────────────────┘


┌──────────────────────────────────────────────────────────────────────┐
│ 改写规则 P3 : 原始垫话命中「越权指令」关键词                                │
├──────────────────────────────────────────────────────────────────────┤
│ 触发条件 : 垫话中出现以下任一关键词                                       │
│   ├─ 发给 / 发送 / 您发 / 转接 / 接通 / 连线 / 您连接                     │
│   └─ 联系 / 您预约 / 您安排 / 马上安排                                   │
│ 替换方式 : 整句替换（原句完全丢弃）                                       │
│ 替换结果 : 从以下 4 条中随机 1 条                                        │
├──────────────────────────────────────────────────────────────────────┤
│ ① 请您稍等。                                                          │
│ ② 请您稍等一下。                                                       │
│ ③ 请您稍等片刻。                                                       │
│ ④ 麻烦您稍等一下。                                                     │
├──────────────────────────────────────────────────────────────────────┤
│ 示例 : 「好的，我马上帮您转接。」 → 「请您稍等。」                            │
│         「我帮您预约一下。」 → 「请您稍等一下。」                            │
└──────────────────────────────────────────────────────────────────────┘


┌──────────────────────────────────────────────────────────────────────┐
│ 改写规则 P4 : 原始垫话含「您说的这个。」                                   │
├──────────────────────────────────────────────────────────────────────┤
│ 触发条件 : 垫话中精确包含「您说的这个。」（带句号）                            │
│ 替换方式 : 短语替换（句子其余部分保留）                                    │
│ 替换结果 : 将该短语替换为以下随机 1 条                                     │
│   ├─ 您说的这个问题。                                                   │
│   └─ 您说的这个情况。                                                   │
├──────────────────────────────────────────────────────────────────────┤
│ 示例 : 「好的，您说的这个。」 → 「好的，您说的这个问题。」                     │
│         「嗯，您说的这个。」 → 「嗯，您说的这个情况。」                       │
│ 注意 : 变体「您说的这个，」（逗号）不触发本规则                               │
└──────────────────────────────────────────────────────────────────────┘


┌──────────────────────────────────────────────────────────────────────┐
│ 改写规则 P5 : 与上一次客服垫话重复                                        │
├──────────────────────────────────────────────────────────────────────┤
│ 触发条件 : 同时满足                                                     │
│   ├─ 本次垫话长度 > 3                                                  │
│   └─ 本次垫话 包含于 上次客服垫话（单向判断）                              │
│       上次垫话 = 最近一条客服语句第一个「。」之前的内容                      │
│ 替换方式 : 按顺序匹配下方替换表，改一处后立即停止                           │
│ 替换表（双向，old ↔ new）                                              │
│   ├─ 嗯，          ↔  嗯嗯，                                          │
│   ├─ 了解了。      ↔  明白了。                                         │
│   ├─ 了解。        ↔  明白。                                          │
│   ├─ ，好，        ↔  ，好的，                                         │
│   └─ 我帮您看一下  ↔  我帮您确认一下                                     │
├──────────────────────────────────────────────────────────────────────┤
│ 示例 : 上次「嗯，您说的这个情况我了解了。」                                 │
│         本次「嗯，您说的这个情况我了解了。」                               │
│         → 命中「嗯，」→ 替换为「嗯嗯，您说的这个情况我了解了。」               │
│ 注意 : 若本次垫话不匹配替换表中任何规则 → 原样重复下发（去重失败）             │
└──────────────────────────────────────────────────────────────────────┘


════════════════════════════════════════════════════════════════════════════
【三】改写规则覆盖优先级速查
════════════════════════════════════════════════════════════════════════════
│ 优先级 P1 > P2 > P3 > P4 > P5 > 原样下发                                    │
│                                                                           │
│ 组合命中时只有前序规则生效，例如：                                              │
│   ├─ 含「转接」+ 含「您说的这个。」→ 只走 P3（整句替换）                          │
│   ├─ 含「查一下」+ 含「记下」→ 只走 P1（整句替换）                              │
│   └─ 整句替换后，被替换的句子不再参与后续短语/去重判断                            │
│                                                                           │
│ 敏感词拦截、空对话拦截 优先于以上全部改写规则                                    │
